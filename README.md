### Configuration
You can either create a new section, give it a full width and place it at the top of the dashboard (make sure that the header section is empty), or you can put it in the header section of the dashboard.
It is recommended to use the header section since that will allow extra options for badges.

##### NOTE: The badges configuration will NOT work when this card is not placed in the header section! See badges instructions below on how to use it inside the header section.

### Badges
Badges can ONLY be added if this card is placed in the header section of your dashboard. You can do this by adding the card to any slot on your dashboard
- Click on a section (red arrow) and add the HKI-Header-Card. You do not need to configure it now if you do not want to, it is configurable once inside the header section.
- Edit the HKI-Header-Card and click on `Show Code Editor` so you can see the full code. Copy this code!
- Click on add title (yellow arrow) and again click on `Show Code Editor`, select all and paste the code we have just copied.
- Done! You can now either continue to use the Code Editor or just the Visual UI editor.

You can add badges via the header section as normal, though once the card is placed inside this section the badges can be manipulated via the settings in the UI.
